# 事故录音转写 · 敏感短语遮蔽（React 单页）

在事故录音转写稿公开前，由披露专员遮蔽数万条敏感短语。页面从符合规约的
JSON 文件加载原文与短语表，实时生成 **# 遮蔽预览**，支持增改、启停、
删除短语，可把当前预览**采纳为下载稿**、放弃调整回到采纳快照，或下载
与屏幕逐字符一致的 UTF-8 文本。

## 输入文件规约

JSON 根对象**仅含**两个键：

| 键 | 类型 | 约束 |
| --- | --- | --- |
| `text` | string | 至多 **2,000,000 个 UTF-16 代码单元**；每个代码单元只能是换行 `U+000A` 或可打印 ASCII `U+0020`–`U+007E` |
| `patterns` | string[] | **1–50,000** 个**互不重复**字符串；每项长度 **1–200 个 UTF-16 代码单元**，仅含 `U+0020`–`U+007E`；全部项总长 ≤ **300,000 个 UTF-16 代码单元** |

不符合上述任一条件（含 JSON 语法错误、根对象多余/缺失键、类型错误），
页面显示 **INVALID_INPUT** 并清除整个会话（原文、工作短语、采纳稿全部
清空）。

## 遮蔽语义（固定，按 UTF-16 代码单元）

- 字符串长度与索引一律按 **UTF-16 代码单元**（即 JavaScript `string`
  的 `length` / `charCodeAt` 语义），**不是** Unicode 码点，也不是字节。
  合法输入只有 ASCII 与换行，因此一个代码单元即一个字符；校验层拒绝任何
  越界代码单元（含代理项、多字节字符）。
- **区分大小写**：`Foo` 不命中 `foo`。
- **不跨换行**：短语本身不含换行；扫描遇到 `U+000A` 时匹配状态复位，
  换行两侧不会连成一次命中。**换行符本身永不替换。**
- 属于任一**完整匹配**的代码单元替换为 `#`，其余字符**原位保留**。
- 命中区间互相重叠、嵌套或相邻时，只取所有命中区间的**覆盖并集**，
  每个代码单元至多输出一个 `#`。
- 输出的 UTF-16 代码单元数与原文严格相等。

非法编辑（空串、与其他启用项重复、字符越界、长度 1–200 越界、启用项
数量或启用总长越过 50,000 / 300,000 上界）显示 **INVALID_PATTERN**，
本次编辑被拒绝，**不覆盖已采纳稿**。

## 算法与性能

- **Aho–Corasick 自动机**：Trie + 失效链，稀疏出边存于开寻址哈希表，
  失效链上的最长命中长度在构建时传播到每个节点。
- 扫描自左向右一遍，在每个代码单元记录“在此结束的最长命中长度”；
  再自右向左一遍合并相邻/重叠区间，直接写入 `Uint16Array` 代码单元缓冲，
  分块解码为字符串。
- 总时间 **O(文本长度 + 模式总长)**，**不按命中数展开**（不生成命中
  区间数组，深度嵌套的海量重叠命中不会放大开销）。预览在常规桌面浏览器
  对 2,000,000 代码单元文本 + 50,000 条模式在 **3 秒内**生成（Node 参考
  环境构建与扫描合计约 0.2–0.3 秒，见性能测试）。
- 每次增改、启停短语都**从原文重新计算**，预览不做增量修补。

## 页面工作流

1. 选择 JSON 文件加载（非法 → INVALID_INPUT，会话清空）。
2. 短语面板：复选框**启停**、点击行内文本**修改**、删除、底部输入框
   **新增**；非法操作显示 INVALID_PATTERN。
3. 实时预览面板展示当前遮蔽结果（大文本以 `textContent` 直接写入，
   不经 React 节点协调）。
4. **采纳为下载稿**：把当前预览逐字符定格为下载稿，并保存短语快照。
5. 采纳后继续调整时，**放弃调整**把短语集恢复到采纳稿快照（采纳稿保留，
   可再次采纳覆盖）。
6. **下载**：`redacted.txt`（`text/plain;charset=utf-8`），字节内容即
   采纳稿字符串经 UTF-8 编码的结果，与屏幕显示**逐字符一致**（包括换行）。

## 本地开发

```bash
npm ci          # 或 npm install
npm run dev     # Vite 开发服务器
npm test        # Vitest：朴素预言机对照 + 高重叠长文本 + 校验/会话
npm run build   # tsc 类型检查 + Vite 生产构建（产物 dist/，已被 .gitignore 排除）
npm run preview
```

测试说明（不固定结果）：

- 随机用例由固定种子的伪随机生成器**即时生成**，用朴素预言机
  （`indexOf` 枚举全部出现位置、含重叠，布尔数组取并集）逐字符对照；
- 高重叠长文本用例：200 条 `a^1..a^200` 对 2,000,000 个 `a`（全遮蔽、
  3 秒内）、50,000 条互不重复模式对 2,000,000 长度文本（3 秒内、输出
  长度不变、`#` 数量等于遮蔽计数）。仓库**不包含**预先算好的固定遮蔽
  结果文件。

## Docker Compose

```bash
docker compose up --build            # 默认 http://localhost:8080
WEB_PORT=9000 docker compose up      # 覆盖发布端口
```

- `web`：nginx 托管 Vite 构建产物，宿主机发布端口由环境变量
  **`WEB_PORT`** 覆盖（默认 `8080`），容器内监听同一端口。
- `verify`：**一次性验收服务**，构建并运行 `npm test`（Vitest 全套）
  后退出；`web` 通过 `depends_on: verify: service_completed_successfully`
  仅在验收通过后启动。

```bash
docker compose run --rm verify       # 单独运行一次性验收
```

## 项目结构

```

src/lib/validate.ts  文件与短语校验
src/lib/session.ts   会话 reducer（工作层/采纳稿两层状态）
src/ui/App.tsx       React 单页
test/                Vitest：朴素预言机、高重叠长文本、校验、会话
docker/              nginx 模板
```
